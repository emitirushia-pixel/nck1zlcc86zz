    SETUP

    ~/setup — PCでの使い方
    game-intel@hud:~/setup$ cat README.txt # PCでの使い方
    1. ファイルとして置く：上の「⬇ PC用ファイルを保存」ボタンで game-hud.html をダウンロードして、デスクトップなど好きな場所へ。ダブルクリックでブラウザが開きます（ネット接続時のみフォント表示が完全になります）。
    2. Wallpaper EngineのWeb壁紙にする：Wallpaper Engineで「壁紙を作成／編集」→ Web壁紙を選び、保存した game-hud.html ファイルを指定すると、デスクトップ背景として常時表示できます。時計とカウントダウンは開いたまま自動で進みます。
    3. フルスクリーンで眺める：「⛶ フルスクリーン」ボタンで全画面表示。サブモニターに置いておくのもおすすめです。
    4. モジュールの自動切替：ゲーム情報は4ページに分かれ、25秒ごとにフェードで自動で切り替わります（締切リストとカウントダウンは常に表示）。モジュール上部の PAGE 01 / 04 表示と ◀ ▶・数字ボタンで手動でも送れます。❚❚ で自動切替を止められます。
    5. カウントダウンについて：左上のゲージは黒い砂漠の定期メンテナンス（毎週木曜 08:00〜12:00 JST）までの残り時間を、日付から自動で計算して表示します。メンテ中は「メンテ中」表示になり、終了予定までのカウントに切り替わります。メンテがない週や時間が変わる週は、公式のお知らせが優先です。
    6. 質問窓（ASK）：4ページ目のパネルです。壁紙の中では文字入力ができないため、パネルをクリックするとブラウザで muse.ai が開きます。質問は開いた先でどうぞ。
